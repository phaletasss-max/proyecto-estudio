[+] RETO: Análisis Forense de Infraestructura Windows Server 2022
[+] ESCENARIO:
    Tu instructor te ha encargado auditar la infraestructura de red
    del laboratorio de SENATI. Tienes acceso a los registros de consola
    de 3 Máquinas Virtuales que ejecutan los siguientes servicios:

    VM1 — Windows Server 2022: DNS, DHCP, File Server, Web Server (IIS)
    VM2 — Router/Gateway Linux: NAT, Firewall, Enrutamiento WAN
    VM3 — Cliente Windows 10: Workstation de un estudiante

[+] OBJETIVO:
    Analiza los archivos de log de cada VM. Identifica qué rol cumple
    cada máquina, qué servicios ejecuta, y encuentra la IP pública
    por la que el gateway enruta todo el tráfico hacia Internet.

[+] PREGUNTA:
    ¿Cuál es la dirección IPv4 pública asignada a la interfaz WAN
    del Router Gateway que permite la salida a Internet?

[+] FORMATO DE LA FLAG:
    HTB{IP_HALLADA}

[+] PISTAS:
    - Busca la interfaz marcada como "WAN" o "UPLINK" en el gateway.
    - Revisa la tabla de enrutamiento (ip route / route print).
    - Observa la salida de tracert desde el cliente.
    - Analiza las reglas NAT (iptables / MASQUERADE).
