[1] PASOS PARA DESPLEGAR TU SITIO WEB CON DOMINIO PROPIO EN VERCEL & GIT
========================================================================

PASO 1: Subir tu proyecto a GitHub
----------------------------------
1. Abre tu terminal en la carpeta del proyecto.
2. Ejecuta los siguientes comandos:
   git init
   git branch -M main
   git add .
   git commit -m "feat: initial commit"
   git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   git push -u origin main

PASO 2: Importar el repositorio en Vercel
-----------------------------------------
1. Entra a https://vercel.com/new
2. Selecciona tu repositorio de GitHub.
3. En "Framework Preset" elige Vite (o React / Next.js).
4. Build Command: npm run build
5. Output Directory: dist
6. Presiona "Deploy".

PASO 3: Vincular tu Dominio Personal (ej. tudominio.com)
------------------------------------------------------
1. En Vercel, ve a: Project Settings -> Domains.
2. Escribe tu nombre de dominio (ej. tudominio.com) y presiona "Add".
3. En el proveedor donde compraste tu dominio (Namecheap, GoDaddy, Cloudflare, etc.), agrega estos registros DNS:

   REGISTRO A:
   - Host: @
   - Valor / IP: 76.76.21.21

   REGISTRO CNAME:
   - Host: www
   - Valor: cname.vercel-dns.com

4. ¡Listo! Vercel generará el certificado SSL HTTPS automáticamente en menos de 2 minutos.
